# Task-1-ComPract-2
Навчальне завдання з комп'ютерного практикуму №2 (завдання 1).
## Опис
Програма мовою C++, за допомогою якої обчислюється функція y з урахуванням умови завдання 1 (КП 2)
## Умова завдання
Написати програму мовою C++, яка обчислює значення функції y залежно від
заданої умови. Для вибору потрібної гілки обчислень використати умовні
оператори "if / else" та логічні значення "true / false".
